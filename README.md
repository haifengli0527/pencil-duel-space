# 紙上彈筆對戰:太空版

小時候在紙上玩的「彈筆對戰」,搬到了外太空。純前端、單一 HTML 檔案、沒有建置流程,用瀏覽器打開就能玩。

## 玩法

開局前先猜拳(剪刀、石頭、布,點手勢圖案,不是文字按鈕)決定誰先手:贏的一方是藍方、優先開始放置棋子,避免固定由某一方(例如建房間的人)先手造成的優劣勢。

雙方各有 10 艘太空船。藍方先在左半邊自由點擊放置全部船艦,放完後再點選其中一艘封為「旗艦」(雙重生命,被打中一次不會馬上陣亡)。接著換紅方在右半邊放置並選旗艦。

正式開打後兩人輪流出手:按住自己的一艘船,往想要的方向的**反方向**拖曳,放開後船會往另一邊彈射出去並畫出一條航跡——但拖曳時只會看到大概的瞄準方向,實際落點與是否命中要放開才會揭曉,**力道越大、方向越難控制**。

- 航跡掃過對方的船,那艘船就會損失一條生命,生命耗盡才會陣亡。
- 棋盤中央有一條**小行星帶**,船的最終落點如果停在裡面就會直接墜毀。
- 棋盤邊界是**黑洞**,力道拉過頭、衝出邊界的船也會直接被吞噬消失——拉滿力道不是零風險的事。
- 雙方陣地最深處各有一座**基地**,只要精準降落進「對方」的基地核心,就能直接獲勝——不用殲滅對方也能靠奇襲取勝!基地的可視範圍做得很顯眼,但真正判定命中的核心範圍刻意比一般船艦還小,考驗真正的精準度。

誰先把對方全部消滅、或搶先攻進對方基地,就獲勝。

## 特色

- **猜拳決定先手**:剪刀石頭布,手勢圖案點選,不是文字選單,贏的一方才是藍方、優先出手,避免固定由某一方(例如建房間的人)佔先手優勢。
- **不確定的彈射手感**:發射方向會依拖曳力道疊加隨機角度誤差(輕彈幾乎精準、大力拖曳明顯難控制),重現紙上遊戲「賭一把」的樂趣,而不是純幾何瞄準。
- **本機雙人(Hot-seat)**:兩人共用一台裝置輪流操作。
- **線上對戰(中繼連線)**:透過免費公開的 MQTT broker(HiveMQ)轉送訊息,不需註冊帳號、不需自架伺服器。建立房間會產生一組 5 碼房間代碼,分享給朋友輸入即可連線對戰。只要瀏覽器能開 WSS 443(一般家用網路、4G/5G 行動網路都行),就保證連得上,不再受 NAT / TURN 限制。
- **手機/觸控支援**。
- 尊重瀏覽器的「減少動態效果」(`prefers-reduced-motion`)與鍵盤 focus 樣式。

## 已知限制

- **連線透過免費公開的 MQTT broker(HiveMQ)中繼,不保證 SLA**:如果 broker 暫時不穩、或所在網路連不上它,就可能無法開房或加入。一般一局只有兩條連線,不容易觸發限流,但短時間內大量重連仍可能被暫時擋住。
- **不是點對點直連**:所有遊戲訊息都會經過中繼伺服器轉送,延遲比 WebRTC 直連略高(通常 100-300ms),回合制的彈筆玩法感受不到差異。訊息內容本身沒有加密(與一般公開網頁相同)。
- **同一台電腦、用不同瀏覽器視窗測試**:可以用,但最準的驗證方式還是找朋友在不同網路環境下實際對戰。

## 技術

- 純 SVG + vanilla JavaScript,無框架、無建置工具。
- 網路對戰使用手刻的 MQTT 3.1.1 client(WebSocket 傳輸),透過免費公開 broker(HiveMQ)中繼,零外部依賴。
- 字型:Google Fonts 的 Noto Sans TC。
