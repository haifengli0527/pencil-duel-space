# 紙上彈筆對戰:太空版

小時候在紙上玩的「彈筆對戰」,搬到了外太空。純前端、單一 HTML 檔案、沒有建置流程,用瀏覽器打開就能玩。

## 玩法

雙方各有 10 艘太空船。開局時藍方先在左半邊自由點擊放置全部船艦,放完後再點選其中一艘封為「旗艦」(雙重生命,被打中一次不會馬上陣亡)。接著換紅方在右半邊放置並選旗艦。

正式開打後兩人輪流出手:按住自己的一艘船,往想要的方向的**反方向**拖曳,放開後船會往另一邊彈射出去並畫出一條航跡——但拖曳時只會看到大概的瞄準方向,實際落點與是否命中要放開才會揭曉,**力道越大、方向越難控制**。

- 航跡掃過對方的船,那艘船就會損失一條生命,生命耗盡才會陣亡。
- 棋盤中央有一條**小行星帶**,船的最終落點如果停在裡面就會直接墜毀。
- 棋盤邊界是**黑洞**,力道拉過頭、衝出邊界的船也會直接被吞噬消失——拉滿力道不是零風險的事。
- 雙方陣地最深處各有一座**基地**,只要精準降落進「對方」的基地核心,就能直接獲勝——不用殲滅對方也能靠奇襲取勝!基地的可視範圍做得很顯眼,但真正判定命中的核心範圍刻意比一般船艦還小,考驗真正的精準度。

誰先把對方全部消滅、或搶先攻進對方基地,就獲勝。

## 特色

- **不確定的彈射手感**:發射方向會依拖曳力道疊加隨機角度誤差(輕彈幾乎精準、大力拖曳明顯難控制),重現紙上遊戲「賭一把」的樂趣,而不是純幾何瞄準。
- **本機雙人(Hot-seat)**:兩人共用一台裝置輪流操作。
- **線上對戰(P2P)**:透過 [PeerJS](https://peerjs.com/) 建立 WebRTC 點對點連線,不需伺服器、不需註冊帳號。建立房間會產生一組 5 碼房間代碼,分享給朋友輸入即可連線對戰。
- **手機/觸控支援**。
- 尊重瀏覽器的「減少動態效果」(`prefers-reduced-motion`)與鍵盤 focus 樣式。

## 已知限制

- **連線對戰目前只設定了 STUN、沒有 TURN 轉發伺服器**。多數一般家用網路對家用網路可以直接連上,但如果雙方任一邊在嚴格 NAT、對稱型 NAT,或行動網路(4G/5G)後面,有可能建立不了直連。之前掛過一組免費公用 TURN(Open Relay Project),經實測已完全失效(測不出任何 relay 候選位址),所以先移除,避免造成「有裝但沒用」的假象。如果你想自己接一個可靠的 TURN(例如 [metered.ca](https://www.metered.ca/) 的免費方案),歡迎發 PR。
- **在同一台電腦、用不同瀏覽器測試連線,不是可靠的測試方式**:很多家用路由器不支援「NAT hairpinning」,同一個區網內的兩個裝置沒辦法透過路由器的外部 IP 互相繞回來連線,就算功能本身正常也可能測不出來。要驗證連線功能,建議找朋友在不同網路環境下實際測試。
